# Evacuation-Protocol-Japanese-Project
日本人たちが集まるプロジェクトです！

## 🎒 対象年齢について
- **基本の対象年齢：** プロジェクトの対象年齢は **12歳以上** とします。
- **GitHubの操作：** GitHubのアカウントを作って操作する人は、規約のため **13歳以上** を対象とします。
- **12歳未満（小学生など）の参加について：** 12歳以下の方が参加する場合は、必ず親御さん（保護者）から許可をもらって参加してください。
※その際、別の特設サイトにて「保護者同意書（利用の同意）」を書いてもらう必要がありますので、ご了承ください。

## ⚠️ 注意事項（必ずお読みください）
みんなが楽しく、安心してゲーム開発に集中できるように、以下のルールを守ってください。

- **迷惑行為の禁止：** 悪口や嫌がらせ、性的な目的を持った方は、このプロジェクトに参加することはできません。
- **違反した場合のペナルティ：** もし悪口などの注意事項に違反する行為を見つけた場合は、プロジェクトの開発メンバーから外れてもらいます。（※1回目の違反については、状況を見て判断します）
- **ルールの変更について：** プロジェクトの状況に合わせて、対象年齢などのルールが変更されることがあります。その際、事前の連絡がいかない場合がありますので、あらかじめ申し訳ございませんがご了承ください。
