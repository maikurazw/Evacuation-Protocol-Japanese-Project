## 🇯🇵 日本語プロジェクト案内（中学生・学生の参加大歓迎！）

**「誰もコードを書いていない今だからこそ、君が最初の開発メンバーになれる！」**

このプロジェクトは、日本人の有志が集まって、ブラウザで動く本格的な脱出FPSゲーム『Evacuation Protocol』をゼロから作るプロジェクトです。

### 🎒 対象年齢について（中学生もOK！）
- **プロジェクトの対象年齢：** **12歳以上**なら誰でも大歓迎！（中学生から参加できます）
- **GitHubのアカウント担当：** GitHubの規約により、掲示板への書き込みやコードの提出は**13歳以上**の方が対象となります。
※ 12歳（中学1年生など）でまだ13歳になっていない方は、お父さんやお母さんと一緒にアカウントを作って参加してくださいね！

### 🤫 このプロジェクトの「3つの安心ルール」
中学生や初心者の方が、緊張せずに自分のペースで楽しく参加できるように、以下のルールで運営しています。

1. **会議なし・音声通話（Discordなど）なし！**
   お互いに喋る必要は一切ありません。すべてのやり取りは、このGitHubの「テキストチャット（掲示板）」だけで静かに、丁寧に進めます。
2. **最初はコードが書けなくても大丈夫！**
   「こんな武器を出したい」「ステージはこんな見た目がいい」といった、テキストでのアイデア出しだけで大歓迎です。
3. **年齢や実力で差別しません！**
   送られてきたテキストやアイデアの「面白さ」だけで対等に評価します。大人のエンジニアに混ざって、ゲーム開発の最前線を体験してみませんか？

### 📥 参加する方法
1. 画面上の **[Issues]**（掲示板）タブを開きます。
2. **「アイデア募集」**という日本語の掲示板が立っているので、そこにあなたの考えた武器やアイテムのアイデアをテキストで書き込むだけで、今日から君も開発メンバーです！
